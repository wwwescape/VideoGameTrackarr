# Platform logos

Logos shown on **Games → Platforms**. Drop a file here named after the platform's IGDB slug and rebuild; no code change is needed.

- Name: `<slug>.<ext>`, e.g. `ps5.png`, `switch.svg`, `win.webp`, `n64.png`.
- Formats: `.png`, `.svg`, `.webp` or `.jpg`. A transparent background works best, since cards use the theme's surface colour in both light and dark mode.
- Slugs ignore IGDB's `--N` suffix, so `ps4.png` also covers a platform stored as `ps4--1`.
- A platform's slug is in the address of its page: `/games/platforms/<slug>`.

Platforms without a logo show their short name (e.g. "PS5") instead.
